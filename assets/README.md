# Project artwork

`argon-ups-source.png` is the original generated transparent PNG.
`icon.png` is the 512px repository version. The integration ships transparent
256px `brand/icon.png` and 512px `brand/icon@2x.png` versions, resized with Pillow
using Lanczos resampling. The emblem is original community artwork, not an
official Argon40 mark. Generated with the built-in image generation tool.

Generation prompt:

> Use case: logo-brand. Asset type: square icon for a community Home Assistant integration and GitHub repository named Argon UPS. Create one polished, friendly, distinctive compact emblem: a small dark graphite uninterruptible power supply with a luminous turquoise battery face and a bold warm amber lightning bolt, subtly suggesting a protective home silhouette. Modern premium technology mascot, restrained rounded forms, slight dimensional depth, crisp large shapes recognizable at 48px, centered composition with generous padding. No lettering, no words, no official brand logo, no watermark, no tiny decorative details. Transparent background with real alpha. This is an original community project identity, not an official Argon40 logo.
